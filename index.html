A. Profil Saya

halo! nama saya hafiz tegar maharaja, saya adalah mahasiswa aktif program studi sistem informasi di fakultas ilmu komputer. saya memiliki ketertarikan yang besar dalam bidang pengembangan aplikasi web, perancangan basis data, serta analisis sistem informasi. saya senang mempelajari teknologi baru yang dapat membantu menyelesaikan beberapa permasalahan di bidang teknologi informasi. selain itu, saya juga tertarik untuk mengembangkan kemampuan dalam pemrograman dan pembuatan sistem yang mudah digunakan. selama menjadi mahasiswa, saya terus berusaha meningkatkan pengetahuan dan keterampilan melalui berbagai tugas dan proyek perkuliahan.

Halaman web ini dibuat menggunakan htmls murni tanpa menggunakan css untuk memenuhi intruksi pembuatan struktur dasar web. dalam pembuatan halaman ini, saya menggunakan berbagai tag html untuk menyusun struktur dan menampilkan informasi. saya juga mempelajari fungsi dari setiap tag agar dapat digunakan sesuai dengan kebutuhan halaman web. Pembuatan halaman ini menjadi salah satu latihan untuk memahami dasar-dasar pengembangan web. Dengan latihan ini, saya berharap dapat memahami HTML dengan lebih baik dan mampu menggunakannya dalam membuat halaman web yang lebih kompleks.
